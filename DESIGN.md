# Следующий шаг: OCR

Этот стартовый проект обрабатывает XML, TXT и PDF с текстовым слоем. Для сканированных PDF добавьте в `read_pdf()` fallback:

1. Если извлечённого текста мало (`len(text.strip()) < 50`), рендерить страницы `PyMuPDF` с матрицей 2x–3x.
2. Передавать изображения в `pytesseract.image_to_data(..., lang="rus")`.
3. Сохранять OCR confidence и ставить `needs_legal_review=True`, если confidence ниже выбранного порога.

Не добавляйте OCR до проверки README набора: там могут быть ограничения, влияющие на метрики.
